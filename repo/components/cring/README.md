# Enam Pilihan CRing Project

Komponen ini hanya memuat enam rentang yang ditetapkan dalam
`support/CRING_SELECTED_SPANS.json`, bukan seluruh CRing Project. Otoritasnya
adalah ZIP resmi SHA-256
`151cdf5498622251db9999b082c4b756a5a7e22b07ddd79538c0057472a4234d`
dan PDF resmi SHA-256
`9d228183f549ab4a64dcacfa49884c0f7ef4d5d5f8c535f9066070bf909b580c`.

Sembilan perbaikan dicatat dalam `support/CRING_REPAIR_GATE.json`; jembatan
orisinal tetap ditandai dan tidak disamarkan sebagai prosa sumber. Komponen
termodifikasi ini memakai GFDL 1.2-or-later tanpa Bagian Invarian dan tanpa
Teks Sampul. Salinan lisensi lengkap ada di `support/GFDL-1.2-or-later.tex`.
